# Spotify 聴きながら読む PiP ウィンドウ

Spotifyのポッドキャスト「聴きながら読む」をブラウザのピクチャーインピクチャーで表示します：現在の文を自動ハイライト、シークバーのクリック/ドラッグ移動、15秒スキップ対応。拡張機能不要の純粋なブックマークレットです。

> 🌏 他の言語：[English](README.md) | [简体中文](README.zh-CN.md)

## なぜTampermonkeyではなくブックマークレットなのか

ブックマークはブラウザアカウントでネイティブ同期されます。Edge/Chromeにログインすれば、全デバイスのブックマークバーに自動反映され、設定は不要です。Tampermonkeyのスクリプト同期はChrome SyncやWebDAVの手動設定が必要です。ブックマークレットは拡張機能に依存しないため、拡張機能が無効でも動作し、バックアップもブックマークHTMLのエクスポートだけで完結します。

Tampermonkeyなどの拡張機能をお好みの場合は、このスクリプトのロジックをuserscriptに移植可能です。セレクタと同期ロジックはすべてここにあります。参考・再利用はご自由に。

## インストール

1. [`bookmarklet.txt`](bookmarklet.txt)を開いて全文コピーします（`javascript:`で始まります）。
2. ブラウザで新しいブックマークを追加し（適当なページでCtrl+Dして編集）、URL欄に貼り付けます。
3. **注意（Edge/Chromeの仕様）：** 貼り付け時に`javascript:`プレフィックスが削除されることがあります。動作しない場合は、ブックマークを編集して先頭に手動で`javascript:`（半角コロン）を入力してください。
4. 名前は自由です（例：「PiP」）。

## 使い方

1. 「聴きながら読む（ベータ）」機能のあるポッドキャストを再生し、「再生中」ビューを開いて聴きながら読むパネルを表示します。
2. ブックマークをクリックすると、PiPウィンドウが開きます：
   - 聴きながら読む（現在の文を自動追従、緑色ハイライト）
   - 再生コントロール：15秒戻る / 再生一時停止 / 15秒進む / 前へ / 次へ
   - シークバー（クリックまたはドラッグで移動）
   - 自動スクロールのオン/オフ（⇅）— 手動スクロール後6秒間は追従を停止

PiPウィンドウを閉じれば元通りです。メインページには影響しません。

## 互換性

- デスクトップ版Edge / Chrome / `documentPictureInPicture`対応のChromiumブラウザ（Chrome 116+）
- Spotifyへのログインが必要（聴きながら読むはログイン限定のベータ機能）

## 仕組み

このブックマークレットはSpotify自身の聴きながら読むコンテナ（`[data-testid="read-along-scroll-container"]`）をPiPウィンドウにクローンし、Spotify自身が管理する既読クラスを同期します（再レンダリングなし）。ハイライトは常にメインページと一致します。シークはプログレスバー内の隠し`input[type=range]`をドライブし、完全なポインタージェスチャーを模擬してReactの状態を一致させます。安定した`data-testid`のみを使用し、難読化されたクラス名には依存しないため、SpotifyのUI更新にも強いです。
